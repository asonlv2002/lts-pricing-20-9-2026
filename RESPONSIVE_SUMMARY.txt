KEY BREAKPOINTS:
- < 640px:   Small mobile (compact padding)
- 640-767px: Large mobile (normal)

- 1100px:    Tablet → Desktop boundary
- Print:     Hide navigation

LAYOUT MODES:

MOBILE (< 768px):
  ├─ Sidebar: 280px drawer overlay (hidden by default)
  ├─ Grid: Single column stacked layout
  ├─ Navigation: FAB button (52x52) + Bottom tab bar (64px)
  ├─ Content: Input form, then results below
  └─ Scrolling: Full page scroll

TABLET (768-1100px):
  ├─ Sidebar: HIDDEN (wastes space - opportunity)
  ├─ Grid: Single column (tab-based)
  ├─ Navigation: Bottom tab bar only (FAB hidden)
  ├─ Content: Input tab OR Result tab (not both)
  └─ Issue: Large tablets waste screen space

DESKTOP (> 1100px):
  ├─ Sidebar: 240px visible (can collapse to 72px)
  ├─ Grid: 300px input | 1fr results (2-column)
  ├─ Navigation: Full sidebar menu
  ├─ Content: Both columns visible and scrollable
  └─ Toolbar: All buttons and controls visible
