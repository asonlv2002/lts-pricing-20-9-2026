CODEBASE EXPLORATION - PHANMEMBAOPI

=== PHU KIEN RENDERING LOCATIONS ===

1. InputCard.tsx lines 391-396
   - Advanced settings section
   - Zipper, Tape, Handle checkboxes
   - Visibility: controlled by advancedOpen state

2. ConfigPage.tsx lines 396-430
   - Admin config for prices/weights
   - Section: 🎀 Giá Phụ Kiện

3. ManagerView.tsx lines 258-260
   - Cost breakdown display
   - Shows per-unit costs


=== PRODUCT TYPE SELECTION ===

Level 1: Select productType (túi or mang)
Level 2A: If túi -> Select bagType (3bien, 4bien, dayDung, cutSeal, etc)
Level 2B: If mang -> Select filmType (mangIn, mangGhepKoIn, mangGhepCoIn)

Handler: handleProductType() clears bagType/filmType when changing


=== STATE MANAGEMENT ===

Type definition: src/lib/types.ts
  - productType: string
  - bagType: string
  - filmType: string
  - hasZipper, hasTape, hasHandle: boolean
  - zipperWeight, tapeWeight, handleWeight: auto-set from constants

Main action: setInput() in calculatorStore.ts
  1. Updates input properties
  2. Auto-calculates profitColumn based on:
     - numLayers >= 3
     - MPET/AL materials
     - bagType === 'dayDung'
     - hasZipper
  3. Auto-assigns weights from constants
  4. Recalculates pricing


=== CONDITIONAL RENDERING ===

Advanced section: visibility based on advancedOpen state
Bag type selector: shown when productType === 'tui'
Film type selector: shown when productType === 'mang'
Structure section: shown when (productType + subtype selected)
Validation: Checked before calculation


=== PROFITCOLUMN LOGIC ===

Critical for pricing:
  profitColumn = 2 if:
    - 3+ layers OR
    - MPET/AL present OR
    - bagType === 'dayDung' OR
    - hasZipper

  profitColumn = 1 otherwise

Impact: Determines profit margin table (col1 vs col2)


=== RESULT DISPLAY ===

Bag type formatted:
  - 3bien -> '3 biên'
  - with zipper -> 'Zipper 3 biên'
  - cutSeal + zipper -> 'Cute seal nắp băng keo' (special case)

Accessories shown conditionally:
  - Chi phí Zipper (if hasZipper)
  - Chi phí Băng keo (if hasTape)
  - Chi phí Quai (if hasHandle)


=== CONFIGURATION ===

Admin edits prices in ConfigPage.tsx section 🎀 Giá Phụ Kiện
Saves to: PUT /api/config/constants
When checked: zipperWeight auto-assigned from constants


=== KEY FILES ===

types.ts - Type definitions
engine.ts - Calculation and validation
calculatorStore.ts - State management with auto-calculations
InputCard.tsx - Product selection and input form
ManagerView.tsx - Result display with formatting
ConfigPage.tsx - Admin configuration


=== INTEGRATION POINTS ===

productType <-> bagType: Sequential, changing one clears other
bagType <-> profitColumn: dayDung always tier 2, +zipper = tier 2
hasZipper <-> Display: Special text for product combinations


=== CRITICAL INSIGHT ===

The key business logic is in calculatorStore.ts line 204:
  bagType === 'dayDung' forces profitColumn = 2
  hasZipper forces profitColumn = 2
  
This directly couples product selection to pricing strategy.
Standing bottom bags and bags with zippers get higher margins automatically.
