========== CORE GRID SYSTEM ==========

CLASS: .main-grid (Line 167)

CSS Definition:
  display: grid;
  grid-template-columns: 300px 1fr;
  gap: 20px;
  align-items: start;

What it does:
  Creates a 2-column CSS Grid with LEFT (300px fixed) + RIGHT (1fr flexible)
  Spacing between columns: 20px
  Alignment: Both columns start at top


========== GRID CHILDREN ==========

LEFT PANEL:
  Class: .grid-col-input
  Width: 300px (from grid-template-columns)
  Height: calc(100vh - 104px) [desktop]
  Content: <InputCard />
  Scrollbar: HIDDEN (but scrolling works)
  Mobile: shown/hidden via .active class

RIGHT PANEL:
  ID: resultArea
  Class: .grid-col-result
  Width: 1fr flexible (fills remaining space)
  Height: calc(100vh - 104px) [desktop]
  Content: <ManagerView /> + <TechView />
  Scrollbar: VISIBLE (6px thin gray)
  Mobile: shown/hidden via .active class


========== DESKTOP BEHAVIOR (801px+) ==========

Page Scroll: DISABLED
  body { overflow: hidden; }
  Each column scrolls independently instead

Column Heights:
  height: calc(100vh - 104px)
  = Full viewport height minus header (~104px)
  Both columns use overflow-y: auto for scrolling

Scrollbars:
  Input: Hidden via display: none on ::-webkit-scrollbar
  Results: Visible, 6px wide, gray colored, rounded corners


========== MOBILE BEHAVIOR (≤1100px) ==========

Mobile Navigation:
  Fixed at bottom of screen
  Height: 64px
  Position: z-index 9999
  Two tabs: "Input" and "Results"

Tab Toggling:
  React state: mobileTab ('input' or 'result')
  Only one grid column visible at a time
  Inactive columns: display: none

Active Tab Styling:
  Text color: accent (blue/indigo)
  Top underline: 3px accent color
  Inactive tab: muted gray color


========== MANAGER CONTENT LAYOUT ==========

Desktop (>1200px):
  .manager-content { padding-right: 180px; }
  TOC positioned: position: absolute; right: 0

Tablet (≤1200px):
  .manager-content { padding-right: 0; }
  TOC repositioned: position: static; width: 100%


========== LAYOUT VARIANTS ==========

Set via [data-layout] attribute on <html>

DEFAULT:
  grid-template-columns: 300px 1fr
  Side-by-side layout

WIDE:
  grid-template-columns: 260px 1fr
  More results space (input narrower)

STACKED:
  grid-template-columns: 1fr
  Single column, vertical stack

BENTO:
  Input: display: none
  Results: 6-column tile grid
